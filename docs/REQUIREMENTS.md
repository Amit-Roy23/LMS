## 2. Open Decisions (To Confirm with Client)

| # | Topic | Description & Options | Current Default / Fallback |
| :--- | :--- | :--- | :--- |
| **D1** | **Payment Gateway Integration** | Which Indian / International payment gateway is preferred? Options: Razorpay, PhonePe UPI, Cashfree, Stripe, or Manual UPI QR. | Abstract payment driver interface implemented; defaults to `MOCK` driver with pluggable `RAZORPAY` adapter stub. |
| **D2** | **Notification Dispatch Channel(s)** | Which channels should receive automated registration & payment confirmations? Options: WhatsApp Business API (Interakt / Gupshup / Twilio), Email (SendGrid / AWS SES / Resend), or SMS (Fast2SMS / Twilio). | Configurable notification driver with templates (`EMAIL`, `WHATSAPP`, `SMS`) and audit logging. |
| **D3** | **Quiz Pool & Question Counts** | Number of questions drawn per attempt for module assessments (e.g., 10 questions vs 20 questions vs all questions in pool)? | Configurable per quiz (`questionCount`, default 20 for Module 1, 10 for Module 2; drawn randomly from 30+ pool). |
| **D4** | **Assessment Pass Mark & Grading** | Standard passing threshold percentage (default 70%; e.g. 14/20 passes, 13/20 fails) and multiple choice scoring mode (`ALL_OR_NOTHING` vs `PARTIAL`)? | Default `passPercentage: 70.0%`, `scoringMode: ALL_OR_NOTHING`, negative marking off (optional 0.25 penalty if enabled). |
| **D5** | **Retake Policies & Cooldowns** | Should students have a maximum attempt limit (e.g., 3-5 attempts) and mandatory cooling-off period between failed retakes (e.g., 5-15 mins)? | Configurable per quiz (`maxAttempts: 3-5`, `cooldownMinutes: 5`). |
| **D6** | **Answer Review Disclosure Policy** | When are correct answers and explanations revealed to students? Options: `NEVER`, `AFTER_PASS` (recommended), `AFTER_EACH_ATTEMPT`, `AFTER_MAX_ATTEMPTS`. | Default `AFTER_PASS` (ensures academic integrity until passing score is achieved). |
| **D7** | **Live Class Video Platform** | Which live streaming / conference provider should be integrated for LIVE batches? Options: Zoom SDK / OAuth, Google Meet API, YouTube Live private unlisted streams, or custom WebRTC. | `LiveProvider` enum (`ZOOM`, `MEET`, `YOUTUBE`, `OTHER`) with `joinUrl` and `recordingUrl` storage. |
| **D8** | **Official Certificate Diploma Layout** | Exact visual seal, signature images, issuer organization accreditation text, and dimensions for vector PDF generation. | High-resolution PDFKit engine with ED25519 hash validation and dynamic verification QR code pointing to `/verify/:certificateId`. |
